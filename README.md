🛠️ 自製網頁編輯小工具

為了方便更新網站上的詩詞與日記，不想每次新增內容都手動修改 HTML，因此利用 AI 協助，以 Python製作了一個簡單的 GUI 編輯工具。

可以直接輸入文章、選擇字體、顏色與寬度，再透過 HTML 模板自動生成固定格式的網頁。

使用方式：

將 blog_manager.py 與 template 下載至同一個新資料夾。

將 template 重新命名為 template.html。

使用 Python 執行 blog_manager.py，即可透過 GUI 編輯文章。

點擊「儲存並發佈到網頁」，程式會自動建立 posts 資料夾並生成 index.html。

產生的 HTML 可直接用瀏覽器開啟，或自行上傳至 GitHub Pages。
